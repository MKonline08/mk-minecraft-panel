# v1.4.1 — Modpack provider settings

Modpacks now has visible CurseForge settings with a password field and Save/Remove controls. Keys persist on the panel and are never returned through the settings API. CURSEFORGE_API_KEY remains supported as a fallback.

The upload error explains that CurseForge exports often contain a download manifest rather than mod JARs. For RLCraft, use the complete Server Pack ZIP for a no-key upload; its author specifies Minecraft 1.12.2 and Forge 14.23.5.2860, with command blocks enabled.

Modrinth search filters out packs declared client-only. Manifest packs without a loader can import as Vanilla. File-download errors now retain the provider's failure reason, and manual replacement uploads are available when automatic downloads fail.

This does not certify arbitrary packs or fix every possible startup failure. Preserve the error text and pack version when reporting an unsuccessful installation.

To update CasaOS, back up the data directory and change the existing panel image to ghcr.io/mkonline08/mk-minecraft-panel:1.4.1, preserving the data mount and host port.
