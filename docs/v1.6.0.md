# v1.6.0 — Public-domain hardening and the neon UI

## Security

- **Setup token.** Set `SETUP_TOKEN` and the first-run screen asks for it, so nobody else can claim the administrator account on a public domain before you do. Two setup requests sent at the same moment can no longer both succeed.
- **Reverse proxy support.** `TRUST_PROXY` (`true`, a number of proxy hops, or proxy IPs/CIDRs) makes login rate limits use real visitor IPs instead of the proxy's.
- **HTTPS by default behind TLS.** Session cookies are marked `Secure` and HSTS is sent automatically when a request arrives over HTTPS. `SECURE_COOKIE=true` still works.
- **Login.** Password hashing no longer blocks the server while it runs, and username checks run in constant time.
- **Headers.** Adds Permissions-Policy, Cross-Origin-Opener-Policy and Cross-Origin-Resource-Policy headers, and a stricter Content-Security-Policy.
- **Docker access.** With `DOCKER_HOST` (for example `tcp://docker-proxy:2375`) the panel can go through a filtering Docker socket proxy instead of the raw socket.
- Backup download filenames are now encoded properly.

## Interface

A refreshed animated theme:

- Animated background and glass panels.
- Glowing hover borders and 3D tilt on server cards.
- Shimmering usage meters and pulsing status lights.
- Click ripples and staggered page animations.
- A CRT-style console.

All motion turns off when the device is set to reduce motion.

## New: running on a public domain

`deploy/docker-compose.domain.yml` runs the panel behind Caddy (automatic HTTPS) with a Docker socket proxy, and the panel itself is not published. Copy `deploy/.env.example` to `deploy/.env`, set `PANEL_DOMAIN` and `SETUP_TOKEN`, then:

```sh
docker compose -f deploy/docker-compose.domain.yml --env-file deploy/.env up -d
```

See the README section "Running on a public domain (HTTPS)".

## Upgrading

Stop your Minecraft servers and back up the data folder as usual. Then change the panel image to `ghcr.io/mkonline08/mk-minecraft-panel:1.6.0`, keeping your existing port and data mount.

Existing LAN installs need no configuration changes. All new settings are optional, and accounts, servers, worlds and backups are preserved.
