# v1.5.3 — Simple Voice Chat UDP ports

Server Settings now includes an optional Voice chat host UDP port. Stop the server, enter 24454, save, then start it. The panel recreates the container with that host UDP port mapped to internal UDP port 24454 while retaining the server files. Additional servers can use separate host ports.

For Playit, point the UDP tunnel to the CasaOS LAN IP and the configured host UDP port. Keep Simple Voice Chat's internal port at 24454 and set voice_host to the tunnel's public address and public port. See docs/voice-chat.md for the full setup.

Update the existing CasaOS panel image to ghcr.io/mkonline08/mk-minecraft-panel:1.5.3, preserving the current ports and data mount. Voice port publishing is opt-in for existing servers. Saving this setting requires the Minecraft server to be stopped.
