# v1.5.2 — Upload a modpack during server creation

Create Server now offers a modpack archive selector. Select a .mrpack, CurseForge export, or complete server ZIP; the panel creates a stopped server, uploads and inspects the archive, then opens the existing review. No pack is applied before confirmation. If upload or inspection fails, the created server remains available so the user can retry from Modpacks. Initial server software and version are placeholders until pack installation changes them.

The import review groups required missing files separately from optional replacements, keeps automatic downloads collapsed, explains why confirmation is disabled, and blocks confirmation when a selected optional file is missing. Upload failures show the server's actual error.

Back up your data before updating. Change the existing CasaOS image to ghcr.io/mkonline08/mk-minecraft-panel:1.5.2 while preserving the existing port and data mount.
